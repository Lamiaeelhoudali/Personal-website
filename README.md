# Personal Portfolio

A simple, responsive personal portfolio website built with HTML5 and CSS3 as part of my Software Development bootcamp with Circuit Stream.

**Live site:** https://lamiaeelhoudali.github.io/Portfolio/

## Built With

- **HTML5** — semantic structure (header, nav, section, article, footer)
- **CSS3** — Flexbox for layout and alignment, linear-gradient backgrounds, box-shadow with opacity for depth, CSS transitions for hover effects, hex color codes
- **Git & GitHub** — version control and deployment via GitHub Pages

## Sections

- **About** — a short introduction
- **Skills** — a flex-wrapped list of core skills
- **Projects** — short write-ups of other projects (About Me landing page, Restaurant Menu, Portfolio Website)
- **Contact** — email and phone

## Reflection

Creating my first portfolio was a rollercoaster of a task, which included challenges and difficulties, but without forgetting the good part of this experience.

First of all, the primary hard part was to put into practice all the elements that we learned during the class, which was not an easy task to do, especially to coordinate everything typed and used in the heading, body, and footer to give me a webpage that is clean, simple, and neat. Implementing the code was a bit challenging, as I tried and failed many times when using the CSS command. The most important thing that helped me nail the process was using the explanation of MDN (Mozilla Developer Network). It has many features that can be used to change the appearance of the webpage and also the overall responsiveness and layouts. I tried and used some of these, which resulted in giving me the outcome I was looking for.

Second of all, I enjoyed this task very much because it gave me the opportunity to know my strengths and weaknesses and also my preferences. On one hand, the way I imagined my portfolio wasn't easy for someone like me who just started learning the fundamentals of software development. On the other hand, it was a rewarding experience, as it allowed me to turn my imagination into reality using the proper path as was explained in class. The heading, the sections, and the footer were some of the major successful tools for me, and adding a little bit of glitter was the amusing part when I used linear-gradient background colors because I wanted to match the same colors of the background image. Another thing was using the box shadow with a level of opacity that allows the background image to be more visible without covering the text in the boxes. Moreover, the use of flexbox and flex gap created an organized layout. The look-alike 3D effect when the cursor comes near the clickable boxes or headings menu makes it change its color, achieved by using transition. Then I used hex color codes because it was easier for me to find the exact color I needed to use.

Finally, the experience was worthy; I enjoyed every part of it, as it led me to the desirable result I was looking for.
